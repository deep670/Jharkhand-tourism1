# 🌄 Jharkhand Tourism

A modern **full-stack tourism platform** designed to showcase the natural beauty, cultural heritage, wildlife, waterfalls, and tourist destinations of Jharkhand.

The platform helps users discover tourist destinations, explore attractions, access useful travel information, and interact with AI-powered features.

## ✨ Key Features

* 🗺️ Explore popular tourist destinations
* 🌊 Discover famous waterfalls and natural attractions
* 🏞️ Explore Jharkhand's scenic landscapes
* 🐘 Discover wildlife and nature destinations
* 🛕 Explore cultural and historical places
* 🔍 Search and explore destinations
* 🤖 AI-powered tourism assistance
* 📍 Destination and travel information
* 📱 Fully responsive design
* ⚡ Fast and modern user interface

## 🤖 AI Integration

The platform integrates **Google Gemini AI** to provide intelligent tourism-related assistance and enhance the overall user experience.

Users can interact with AI-powered features to get useful information related to destinations, travel planning, and tourism.

## 🎯 Project Goal

The goal of this project is to promote **Jharkhand Tourism** through a modern digital platform that makes it easier for visitors to discover destinations, explore attractions, and plan their trips.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/deep670/Jharkhand-tourism1.git
cd Jharkhand-tourism1
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

Open another terminal:

```bash
cd backend
npm install
node server.js
```

Create a `.env` file inside the backend folder and add your required environment variables.
